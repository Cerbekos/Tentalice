# 機能について
- `Tentalice`は、ZMKファームウェアを使用した自作キーボードであり、キーマップのカスタマイズやタップダンスによる複数キーの切り替え、LEDインジケータなどの機能があります。また、トラックボールを搭載しており、トラックボール操作の支援機能として複数の外部モジュールを導入しています。
- これらの機能の一部は、ツールを使用して簡単に自分好みにカスタマイズすることが可能です。
- また、ソースファイルを書き換えることでより細かい設定も可能です。(左手でトラックボールを操作するためにセンサー角度を90度回転させる、等)
