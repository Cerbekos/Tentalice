# ビルドガイド

## 0.組み立て順序
**組み立て順序**は右の `ON THIS PAGE` をご参照ください。
**順序を間違えると復旧が難しい場合があります**ので、組み立て前に一通り手順をご確認ください。

使用するパーツの名称は以下の通りです。
![tenkaizu](../images/tenkaizu.jpg)

なお、以下の部品は予めPCBAにより基板へ取り付け済みです。
- `ダイオード`
- `ホットスワップソケット`
- `FFCコネクタ`
- `PHコネクタ`
- `LED`

また溶接・溶着を円滑にしてくれる`プリント基板用フラックス`を使用すると`はんだ`が乗りやすいため、使用することを強く推奨します。

## 1.ファームウェアの書き込み
**1-1.ファームウェアのダウンロード**
以下のリンクをクリック。
- [Tentalice firwmware](https://github.com/Cerbekos/Tentalice/tree/main/firmware)
ファームウェアの名前をクリック。
![alt text](../images/image-1.png)
ダウンロードをクリックして`uf2ファイル`を保存。
![alt text](../images/image-2.png)

**1-2.ファームウェアの書き込み**
`XIAO BLE`を`USB`で`PC`に接続し、表面の`リセットボタン`を素早く2回押下します。
![alt text](../images/image-3.png)

成功するとブートモードとなり、`XIAO BLE`のドライブが表示されますので、ここへダウンロードした`uf2ファイル`をコピーします。自動的にリブートされ、ファームウェアが書き込まれます。

## 3.LEDの取り付け
PCBA実装済みです。次の手順へ進んでください。
:::details 初期頒布品の場合はこちらを開いて手順を確認してください
本工程はオプションです。`LED`を取り付けなくても動作には支障ありません。

**3-1.位置合わせ**
`LED`には向きがあり、`GND`にある斜めの切り込みが目印です。
![alt text](../images/image-11.png)

メイン基板の背面へ`LED`を画像の向きで乗せ、位置を合わせます。
![alt text](../images/image-12.png)

**3-2.はんだ付け**
端子をはんだ付けします。**`LED`は高温に弱いため、260度程度**に温度を設定してください。
![alt text](../images/image-13.png)

`LED`はメイン基板に4か所取り付けできますので、すべてはんだ付けします。
一度`XIAO BLE`に`USB`を接続して`LED`が点灯するかを確認します。なお、一定時間経過すると自動で`LED`をオフにする制御を入れていますのでご留意ください。
![alt text](../images/image-10.png)
:::

:::details もしLEDが点灯しない場合は
| 原因例 | 対策例 |
| :---- | :---- |
| `LED`のはんだの量が足りていない、または多すぎて隣と接合している | はんだごてやはんだ吸い取り線を使いはんだの量を調整してください |
| `LED`の取り付け向きが誤っている | はんだ吸い取り線を使い、慎重にはんだを除去してから向きを正しくし、はんだ付けしてください |
| `XIAO BLE`のはんだの量が足りていない、または多すぎて隣と接合している | はんだ付けし直したり、多い場合ははんだ吸い取り線などを使い、はんだの量を調整してください |
:::

**4-2.はんだ付け**

## 7.マウスセンサー基板の取り付け
```
ℹ️マウスセンサー基板はばりが残っていると組み立てにくいため、やすりでばりをきれいにしてから
   取り付けてください。
```
本工程では、`PMW3610 マウスセンサー`を`ブレークアウトボード`へ取り付けてから、`L字ピンヘッダ`を使ってメイン基板へ取り付けします。

**7-1.電圧レベルの設定**
`ブレークアウトボード`で3.3Vの電圧に設定するため、**1と2がショート([1-2 3])**するようにジャンパします。
![alt text](../images/image-20.png)

**7-2.PMW3610 マウスセンサーの位置合わせ**
`PMW3610 マウスセンサー`の位置を合わせます。ここで位置を反対に取り付けるとリカバリできないため注意してください。以下の画像のように、**ジャンパに対して反対側に球体がある**向きにします。
![alt text](../images/image-22.png)

位置合わせ後、**マスキングテープで固定してから**、透明のレンズ部品を取り外します。
![alt text](../images/image-23.png)

**7-3.PMW3610 マウスセンサーのはんだ付け**
慎重にすべてのピンをはんだ付けします。
![alt text](../images/image-21.png)

**7-4.L字ピンヘッダの位置合わせ**
`L字ピンヘッダ`は、レンズ部品とは反対面に、ピンが内側に来る向きに位置合わせします。
![alt text](../images/image-24.png)

位置合わせ後、**ピンが正確に90度となっているかを確認し、マスキングテープで固定**します。
![alt text](../images/image-25.png)

**7-5.L字ピンヘッダのはんだ付け**
上手く部品を固定し、ピンをはんだ付けします。
![alt text](../images/image-26.png)

**7-6.メイン基板への取り付け**
メイン基板の背面から`L字ピンヘッダ`を差し込み、マスキングテープで固定します。
![alt text](../images/image-28.png)

角度が90度であることを確認し、表面からピンをはんだ付けします。
![alt text](../images/image-29.png)

はんだ付けの後、黄色の保護シールを剥離し、レンズ部品を取り付けます。

## 8.基板の動作確認
以上ではんだ付けの工程は完了ですので、ここまでの作業で不具合がないかを確認します。

**8-1.キーやセンサーの入力確認**
`XIAO BLE`に`USB`を接続し、テキストエディタを開いて、`各キー`が反応するかを確認します。ただし、現状は**キースイッチ**を取り付けていないため、ピンセットで**各ソケット**の両端を導通させて文字が表示されるかを確認します。また、トラックボールセンサーのレンズに指などを近接させ、マウスカーソルが反応するかを確認します。

:::details もし反応しない場合は
| 原因例 | 対策例 |
| :---- | :---- |
| うまく導通できていない | ピンセットで反応がない場合でもキースイッチを差し込むと上手くいくときがたまにありますので、ピンセットがだめならスイッチをつけて動作確認してみてください |
| `キースイッチ`のはんだ付けの付け忘れ | キーが反応しないとき一番多い原因です。はんだ付けをし直してしてください |
| `XIAO BLE`のはんだの量が足りていない、または多すぎて隣と接合している | はんだ付けし直したり、多い場合ははんだ吸い取り線などを使い、はんだの量を調整してください |
| `マウスセンサー基板やL字ピンヘッダ`のはんだの量が足りていない、または多すぎて隣と接合している | はんだ付けし直したり、多い場合ははんだ吸い取り線などを使い、はんだの量を調整してください |
:::

**8-2.外部電源での動作確認**
外部電源から電力を得た状態で、Bluetooth接続によるキーの入力確認を行います。
向きに注意しながら`LiPoバッテリー`のコネクタ接続します。
![alt text](../images/image-30.png)

起動すると、LEDが点灯したり、Bluetoothがペアリング状態になります。
PCまたはスマートフォンでBluetoothの接続を行います。Bluetooth接続は、初期状態であれば、電源が供給されると自動的にプロファイル０でペアリング開始モードになります。

:::details Bluetooth接続のプロファイルの変更やクリア
初期キーマップではLayer5に配備しています。Layer5は、赤もしくは青のキーを二つ同時押しして入るように設定しています。
![alt text](../images/image-31.png)
:::
:::details もしキーボードが起動しない場合は
| 原因例 | 対策例 |
| :---- | :---- |
| `XIAO BLE`の背面のパッド（BAT＋－）のはんだの量が足りていない、または多すぎて隣と接合している | はんだ付けし直したり、多い場合ははんだ吸い取り線などを使い、はんだの量を調整してください |
| `PHコネクタ`のはんだ付けの付け忘れ | はんだ付けをし直してしてください |
:::

## 10.支持球の接着
`支持球`を`トップケース`に接着します。

**10-1.支持球受けの位置**
以下の3か所に支持球受けがあります。
![alt text](../images/image-41.png)

**10-2.支持球の接着**
支持球受けに、爪楊枝などで接着剤を慎重に垂らし、`支持球`を埋め込みます。

## 11.ケース用マグネットの取り付け
ケース用のマグネットを接着剤で固定します。**マグネットの向きにご注意ください。**

**11-1.ボトムケースへのマグネット接着**
`ボトムケース`の四隅に、爪楊枝などで接着剤を1滴垂らし、マグネットを接着します。接着するまでしばらく待ちます。
![alt text](../images/image-32.png)

**11-2.マグネットを重ねる**
次に、`ボトムケース`の四隅のマグネットに、`トップケース`用のマグネットをくっつけます。これにより向きを間違えて取り付けることを防止します。
![alt text](../images/image-34.png)

**11-3.トップケースを重ねる**
四隅のマグネット上に、爪楊枝などで接着剤を慎重に垂らし、`トップケース`を載せます。マグネット同士が接着剤で接着しないよう量に注意してください。

## 12.キースイッチと左右基板の取り付け
`トップケース`にキースイッチを取り付け、左右基板をキースイッチで固定します。端の方から数個ずつキースイッチと基板を取り付けるように進めてください。

## 13.FFCケーブルの接続
メイン基板と左右基板を繋ぐ`FFCケーブル`を`FFCコネクタ`へ接続します。

**13-1.FFCコネクタとFFCケーブルの接続方法**
`FFCコネクタ`のパネルを上げ、`FFCケーブル`を青色が上面になるようにし、斜めにならないように差し込みます。
![alt text](../images/image-36.png)

その後、パネルを下げて固定します。

**13-2.左右基板の接続**
左右の基板の`FFCコネクタ`と`FFCケーブル`を接続します。
![alt text](../images/image-37.png)

**13-3.メイン基板の接続**
左右いずれかの基板の`FFCケーブル`とメイン基板の`FFCコネクタ`を接続します。
![alt text](../images/image-38.png)

残りの`FFCケーブル`とメイン基板の`FFCコネクタ`を接続します。
![alt text](../images/image-39.png)

## 14.キーキャップの取り付け
`キーキャップ`を`キースイッチ`に嵌め込みます。

## 15.34mmボールの取り付け
最後にトラックボールマウス用の`34mmボール`をボール受けに嵌め込んで動作を確認します。

:::details もしボールが反応しない場合は
| 原因例 | 対策例 |
| :---- | :---- |
| `センサーレンズ`が浮いている | `センサーレンズ`がずれていると反応がしなかったり、弱くなります。ボールを一度取り出して指で`センサーレンズ`を押し込んでください |
:::

以上で、ビルドガイドは終了です。
